🐳 Docker

מדריך אינטראקטיבי ללימוד Containerization

📦מה זה Docker?

Docker היא פלטפורמת קונטיינריזציה שמאפשרת לארוז יישום עם כל התלויות שלו לתוך יחידה סטנדרטית הנקראת Container.

במקום להגדיר כל שרת בנפרד, Docker מאפשר ליצור סביבה אחידה וסגורה שרצה באותו האופן בכל מקום - במחשב המקומי, בשרת, בענן.

💡
חשוב לדעת: Docker שונה מ-VM! בעוד ש-VM מכיל מערכת הפעלה מלאה וקרנל נפרד, Container משתף את קרנל מערכת ההפעלה של ה-Host.

🏆למה Docker חשוב ב-DevOps?

סביבה אחידה (Consistency): מה שרץ אצלי במחשב ירוץ בדיוק אותו דבר ב-production.

בידוד (Isolation): כל שירות (DB, API, Frontend) רץ ב-Container נפרד ולא מפריע לאחרים.

מהירות (Speed): יצירת Container חדש לוקחת שניות, לא דקות כמו VM.

Reproducibility: ניתן לשחזר כל סביבה מחדש בקלות.

🔄VM vs Container

הבדל מרכזי - חלוקת משאבים:

Host OS
מערכת ההפעלה המארחת

🖥️ Virtual Machine

  • מערכת הפעלה מלאה
  • קרנל נפרד
  • צורך Hypervisor
  • זמן הפעלה: דקות
  • גודל: GB

📦 Container

  • שיתוף קרנל ה-Host
  • קל משקל
  • ללא Hypervisor
  • זמן הפעלה: שניות
  • גודל: MB

🖼️Image

Image הוא תבנית (template) ליצירת Container. זה בעצם snapshot שמכיל את כל מה שצריך: מערכת הפעלה קלה, קוד, ספריות, תלויות והגדרות.

Image הוא קריאה בלבד (read-only) - אי אפשר לשנות אותו ישירות. כל שינוי יוצר שכבה (layer) חדשה. 

# שליפת Image מוכן מ-Docker Hub
docker pull ubuntu:20.04

# הצגת כל ה-Images המקומיים
docker images

📦Container

Container הוא מופע רץ (running instance) של Image. אפשר לחשוב על זה כך:

Image = Class (תבנית)

Container = Object (מופע קונקרטי)

כל Container רץ בבידוד מלא - עם מערכת קבצים נפרדת, רשת נפרדת ותהליכים נפרדים.

🏪Docker Hub

Docker Hub הוא מאגר ציבורי ענק של Images מוכנים. תוכל למצוא שם כמעט כל דבר: 

# שליפת Images נפוצים
docker pull nginx        # שרת Web
docker pull postgres:13  # מסד נתונים
docker pull node:18      # Node.js
docker pull redis:7      # Redis cache

🔗Docker Volumes

Volumes מאפשרים לשמור נתונים מחוץ ל-Container כך שהם ישארו גם אחרי שה-Container נמחק. 

# יצירת Volume
docker volume create my-data

# שימוש ב-Volume ב-Container
docker run -v my-data:/app/data my-image

# שימוש בתיקייה מקומית
docker run -v $(pwd)/data:/app/data my-image

🌐Docker Networking

Docker יוצר רשת וירטואלית שבה Containers יכולים לתקשר ביניהם. יש כמה סוגי רשתות:

  • bridge - רשת ברירת מחדל לתקשורת בין Containers
  • host - שיתוף רשת עם מערכת המארחת
  • overlay - ל-Docker Swarm
  • none - ללא רשת

📝מהו Dockerfile?

Dockerfile הוא קובץ טקסט המכיל הוראות לבניית Image. כל שורה מגדירה שכבה (layer) אחת ב-Image.

זה המקום שבו אתה מגדיר איזה Base Image להשתמש, אילו תלויות להתקין, איפה להעתיק את הקוד ואיך להריץ את היישום.

📋פקודות Dockerfile

פקודה תיאור
FROM מגדיר את ה-Image הבסיסי
RUN מריץ פקודה בזמן בנייה
COPY מעתיק קבצים לתוך ה-Image
ADD דומה ל-COPY אבל עם יכולות נוספות
WORKDIR מגדיר תיקיית עבודה
EXPOSE מגדיר פורט לחשיפה
CMD פקודת הרצה בזמן הפעלת Container
ENV מגדיר משתנה סביבה
ENTRYPOINT מגדיר פקודה קבועה להרצה

💻דוגמה מלאה

דוגמה ל-Dockerfile עבור אפליקציית Node.js:

# שלב 1: Base Image
FROM node:18-alpine

# שלב 2: יצירת תיקיית עבודה
WORKDIR /app

# שלב 3: העתקת קובץ תלויות
COPY package*.json ./

# שלב 4: התקנת תלויות
RUN npm install

# שלב 5: העתקת קוד האפליקציה
COPY . .

# שלב 6: חשיפת פורט
EXPOSE 3000

# שלב 7: הרצת האפליקציה
CMD ["node", "index.js"]

⚡Multi-stage Builds

טכניקה לאופטימיזציה של גודל ה-Image - בונים בשלבים ומעתיקים רק את מה שצריך: 

# שלב בנייה - שלב 1
FROM node:18 AS builder
WORKDIR /app
COPY . .
RUN npm run build

# שלב סופי - שלב 2
FROM node:18-alpine
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
CMD ["node", "dist/index.js"]

⌨️פקודות Docker בסיסיות

פקודה תיאור
docker pull image הורדת Image מ-Docker Hub
docker images הצגת כל ה-Images המקומיים
docker run image יצירה והרצת Container
docker ps הצגת Containers פעילים
docker ps -a הצגת כל ה-Containers
docker stop id עצירת Container
docker rm id מחיקת Container
docker rmi image מחיקת Image

🔨בנייה והרצה

# בניית Image מ-Dockerfile
docker build -t my-app:1.0 .

# הרצת Container עם שם ופורט
docker run -d --name web -p 8080:80 my-app:1.0

# הרצה אינטראקטיבית
docker run -it ubuntu:20.04 /bin/bash

# כניסה ל-Container קיים
docker exec -it web /bin/bash

# צפייה בלוגים
docker logs -f web

🧹ניקוי משאבים

# מחיקת כל ה-Containers שנעצרו
docker container prune

# מחיקת כל ה-Images שלא בשימוש
docker image prune -a

# ניקוי הכל (בזהירות!)
docker system prune -a

📄מהו Docker Compose?

Docker Compose הוא כלי להגדרה והרצה של מספר Containers יחד. במקום להריץ פקודות רבות, אתה מגדיר הכל בקובץ docker-compose.yml אחד.

אידיאלי לסביבות פיתוח עם מספר שירותים (למשל: Frontend + Backend + Database).

📋מבנה docker-compose.yml

version: '3'

services:
  # שירות Frontend
  frontend:
    build: ./frontend
    ports:
      - "3000:3000"
    depends_on:
      - api
    environment:
      - API_URL=http://api:5000

  # שירות Backend/API
  api:
    build: ./backend
    ports:
      - "5000:5000"
    environment:
      - DB_HOST=database
      - DB_NAME=mydb

  # שירות מסד נתונים
  database:
    image: postgres:15
    volumes:
      - pgdata:/var/lib/postgresql/data
    environment:
      - POSTGRES_DB=mydb
      - POSTGRES_USER=admin
      - POSTGRES_PASSWORD=secret

volumes:
  pgdata:

⚡פקודות Docker Compose

# הרצת כל השירותים
docker-compose up -d

# הרצה עם שכבוב שינויים
docker-compose up --build

# עצירת כל השירותים
docker-compose down

# עצירה ומחיקת נתונים
docker-compose down -v

# צפייה בלוגים
docker-compose logs -f api

# הרצת פקודה בשירות
docker-compose exec api npm run migrate

🔍הבדלים מ-Dockerfile

Dockerfile docker-compose.yml
מגדיר Image אחד מגדיר מספר שירותים
משמש לבנייה (build) משמש להרצה (run)
בסיס לכל Container מתאם בין Containers
לא מגדיר רשתות יוצר רשת משותפת

📝בוחן ידע - Docker

ענה על השאלות הבאות כדי לבדוק את הידע שלך:

1. מהו ההבדל העיקרי בין Image ל-Container?

אין הבדל - זה אותו דבר
Image הוא תבנית ליצירה, Container הוא מופע רץ
Container גדול יותר מ-Image
Image משמש רק לאחסון נתונים

2. מה פקודת docker run מבצעת?

מוחקת Container
מבנה Image חדש
יוצרת ומריצה Container מ-Image
מעתיקה קבצים

3. איזו פקודה משמשת לבניית Image מ-Dockerfile?

docker build
docker run
docker compose
docker create

4. מה תפקיד הפקודה EXPOSE ב-Dockerfile?

מאפשרת גישה מבחוץ לרשת
מגדירה משתנה סביבה
מריצה פקודה
מגדירה פורט לחשיפה

5. מתי נשתמש ב-Docker Compose?

כשצריך לבנות Image
כשרוצים להריץ מספר שירותים יחד
רק למסדי נתונים
להחלפת Dockerfiles
